# Соответствие требованиям менеджера

| Требование | Реализация | Что проверено / ограничение |
|---|---|---|
| История, остатки, товары в пути, категории, прогноз роста | SQLite, 8 типов импорта, связка товар + склад, параметры сценария и категории | Тест изменения каждого фактора и фильтрации. В переданных CSV есть только готовые прогнозы и агрегаты, отдельные источники подключаются импортом. |
| Сезонность и устойчивый рост | Профиль календарных месяцев, удаление сезонности при оценке роста, ограниченный тренд | Синтетические сезонные и растущие ряды. Реальная точность до получения истории не оценена. |
| Компенсация stockout | Дни доступности и интервалы отсутствия; восстановление частично/полностью недоступных месяцев | Тесты частичного и полного отсутствия. Пустая история доступности явно отмечена. |
| Разовые крупные покупки одному клиенту | Агрегация клиент/день, медиана и MAD; сохранение регулярных больших клиентов | Большой заказ из нескольких строк не увеличивает регулярный прогноз. При отсутствии операций только месячная эвристика. |
| Список по поставщикам и объяснение каждой строки | Группировка, формула карточки, назначения, черновики, CSV | Поставщики в CSV отсутствуют и не выдуманы; назначение обязательное перед черновиком. |
| Проверка → корректировка → утверждение | Флажки выбора, изменение количества с причиной, MOQ, ответственный, подтверждение | Тесты статусов, повторного подтверждения, устаревшего черновика, отсутствующих цен. |
| Риск дефицита | Критичный/высокий/плановый, дни покрытия, сигналы устаревшего остатка | Расчёт по свободному запасу и сроку поставщика; временной провал поставки требует отдельной проверки. |
| MOQ и условия поставщика | Минимум, кратность, срок, минимальная сумма | Серверная проверка создания/утверждения. |
| Визуализация спроса | Баланс запасов по бренду, фильтр категории, прогноз 30/60/90 и помесячная история в карточке | Общий тренд по категориям не реализован: исходной истории нет. Это опциональный пункт. |
| Приватность | Обезличенные хеши клиентов, строгие поля истории, локальный сервер, ключ только на сервере | Корпоративная авторизация/SSO не входит в локальный прототип; необходима перед многопользовательским размещением. |
| Запрет автоматической отправки | Только локальное утверждение и ручной CSV-экспорт | Канал отправки не подключён. |
| Выход для 1С | Код 1С, артикул, поставщик, склад, единица, количество, стоимость в CSV | Требуется согласование схемы импорта конкретной конфигурации 1С. |
| Репозиторий и документация | Исходный код, тесты, методология и инструкция запуска включены в архив | Включён локальный Git-bundle с исходниками. GitHub URL не предоставлен; удалённый репозиторий не опубликован. |

Наличие механизма не означает, что отсутствующие исходные данные уже загружены. В интерфейсе это разделено: готовый прогноз CSV / расчёт по исходной истории.
