# Проверка сборки 2.0

Дата: 23 сентября 2026.

## Автоматические тесты

`python -m pytest -q`: **30 passed**.

В том числе проверены все исходные 1 922 позиции и совпадение рассчитанных количеств с переданными рекомендациями в базовом 30-дневном сценарии (допуск 0.0011). Результат: 367 дефицитных, 1 555 с избытком; дробные метры сохранены.

Синтетические ряды проверяют сезонность, рост, клиентские выбросы и stockout. Тестовые базы создавались отдельно; в поставляемой базе только исходные данные.

Среда: Python 3.12.14, версии зависимостей зафиксированы в `requirements-tested.txt`. Единственное предупреждение тестового раннера — deprecation интеграции Starlette TestClient/httpx; тесты прошли.

## Границы проверки

Windows-запускатель проверен чтением кода и компиляцией Python-части; Windows-среда в этой сессии отсутствует. Требуется установленный Python 3.11+ и интернет при первой установке. Рабочий сервер и UI проверены в Linux.

Реальный OpenAI API, 1С и отправка поставщикам не проверялись и не подключались. Полноценная оценка точности прогноза на исторических реальных данных невозможна без исходных продаж и доступности. Неизвестные поставщики, сроки и цены не заполнялись искусственно.
